# CampusPool Sprint 1 solutions

This repository contains the clean TypeScript implementation in
[`campuspool/`](campuspool/) and reproducible teammate handoff artifacts. The
previous Laravel work remains byte-for-byte under [`legacy/`](legacy/) and is
not part of new PR diffs.

Start with [TEAM_START_HERE.md](TEAM_START_HERE.md), then use the scripts in
[`scripts/`](scripts/) from a fresh clone. Read the shared API and database
contract in [`contracts/IMPLEMENTATION.md`](contracts/IMPLEMENTATION.md).

The implementation evidence is summarized in [reports/SPRINT1_VERIFICATION.md](reports/SPRINT1_VERIFICATION.md). The course-facing mapping remains honest about pending instructor approval, human reviews, screenshots and videos. The application design now presents role/status badges, clearer dashboard actions, responsive cards, keyboard focus states, skip navigation and readable database evidence summaries.
